## How to muster it

1. Choose sync mode: follower, boss, or free-running.
2. Confirm pattern/kit.
3. Patch audio to the mixer and label the channel.
4. Confirm it does not create a second clock boss.

## How to remove it safely

1. Mute its mixer channel.
2. If it owns or forwards clock, assign a new single clock boss before continuing.
3. Confirm the audio lane still carries the set without this drum source.
4. Note the removed pattern/kit in the show postmortem.

## Failure modes

- Pattern starts from unintended external Start.
- It drifts because it is free-running when the set expects sync.
- Output is patched through a processor assumed to be optional.
- Pattern memory or kit choice differs from the documented show state.
