## How to muster it

1. Confirm media, load state, and program.
2. Choose MIDI channel and trigger path.
3. Patch audio output to a labeled mixer channel.
4. Verify load time and failure fallback before relying on it.

## How to remove it safely

1. Leave it out of required show paths unless explicitly tested.
2. Mute or unplug its mixer channel if it causes noise or confusion.
3. Confirm no controller map or sequence depends on it.
4. Capture any useful program/sample state before changing disks or memory.

## Failure modes

- Load time or media state prevents the expected sample set from appearing.
- MIDI channel conflicts with another source.
- Audio output is assumed live but is not patched or gained correctly.
- It gets documented as stable before the real patch is tested.
