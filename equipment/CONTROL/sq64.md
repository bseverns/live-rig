# SQ-64

## Identity

- Category: sequencer / control.
- Status: `core/live`.
- Aliases: Korg SQ-64, `sq64`.

## What it is

Main sequencer, especially for AE rack voices.

## Current rig relationship

Current docs treat SQ-64 as a main sequencing object. AE rack default voice lane is described around channel 16.

## I/O

- MIDI/CV/gate: sequences voices.
- Clock: may follow or participate depending on set; do not assume it is boss.
- Audio: no primary audio role.
- Power: unknown until photographed.
- Current project: unknown until physical verification.

## Verification

- Last physically verified: unknown.
- Verified by: unknown.
- Confidence: manual/memory for general role; unknown for current project and wiring.
- Still unknown: power supply, MIDI/CV/gate patching, port names, track/channel assignments, current clock role, active project/pattern.

## How to muster it

1. Decide clock role.
2. Confirm track assignments and destination channels.
3. Confirm AE rack or other voices respond as expected.
4. Document per-track assignments if they stabilize.

## How to remove it safely

1. Stop its sequence output.
2. Confirm any affected voices are muted or manually playable.
3. If it was clock boss, assign one new boss before continuing.

## Failure modes

- Track/channel assignments drift.
- It forwards clock or transport unexpectedly.
- AE rack appears dead because track routing changed.

## Manual reference

- Sources: `notes/manuals/sq64.pdf` and `notes/manuals/sq64_full.pdf`.
- USB micro-B provides computer MIDI and power; MIDI IN, OUT1, and OUT2 use
  type-A TRS-MIDI converter cables. Sync I/O uses 3.5 mm mono connections.
- A project contains melody tracks A–C plus drum track D; 64 project slots are
  rewritable. Do not confuse a saved project with the current physical patch.
